# Fight Arena

**Fight Arena** is a 3D, single-player fighting game developed in Unity, inspired by classic fighting games, particularly the Tekken series. The project explores fighting-game mechanics, character movement, opponent interactions, and camera systems while aiming to create an engaging combat experience.

## Features and Development Highlights

- **3D Fighting Gameplay:** A fighting experience inspired by classic arena-based fighting games.
- **Character Movement:** Player movement and character orientation during combat.
- **Camera Systems:** Camera positioning and framing designed around the fighters' relative positions and distance.
- **Character Customization:** Character-related customization as listed on the game's itch.io page.
- **Arena Design:** Fighting environments, arena boundaries, and map setup.
- **Animation Integration:** Integrating character animations with gameplay behavior.

## My Work

Fight Arena is a personal game development project through which I explored and implemented gameplay systems in Unity.

My development work has included:

- Implementing and refining player movement and character-facing behavior.
- Working on camera movement, positioning, and framing around the fighters.
- Integrating character animations with gameplay.
- Setting up arena boundaries and fighting maps.
- Iterating on gameplay and presentation to improve the overall experience.

## Development Focus

One of the technical challenges in a 3D fighting game is maintaining a useful camera view while two characters move around the arena. Their relative positions and distance affect how the camera should frame the action.

Working on Fight Arena gave me practical experience in coordinating character movement, camera behavior, and gameplay presentation within Unity.
